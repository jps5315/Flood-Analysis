# Sample data lineage

## Purpose
A **one-watershed** extract so the toolbox finishes in minutes. County-wide live REST
queries use pagination when record counts exceed 2000 to avoid truncation. This sample
demonstrates the pagination approach with HCFCD watershed data.

## Pagination support
The tool now supports live REST API queries with automatic pagination:
- **Threshold:** 2000 records (configurable in `config/settings.json`)
- **Below threshold:** Single query, download as local extract
- **Above threshold:** Paginated queries using `resultOffset` and `resultRecordCount`
- **Example:** 2018 county service has 6,185 records → 4 pagination cycles (2000 + 2000 + 2000 + 185)

## Coordinate systems
GeoJSON files are stored in **EPSG:4326** (GeoJSON default). The ArcPy pipeline
projects them to **EPSG 3083** (NAD 1983 Texas Albers Equal Area, meters)
before any area calculation.

## Sources
- HCFCD REST catalog: https://www.gis.hctx.net/arcgishcpid/rest/services/HCFCD
- Watershed service: `HCFCD/Watershed` (loaded with pagination)
- Flood scenario proxy: `HCFCD/FEMA` / Flood Hazard Zones (3 historical years: [2016, 2017, 2018])
- Parcels: synthetic HCAD-shaped sample (public MapServer is not bulk-downloadable)
- Depth rasters: NOT generated by this script. In production, depth rasters come from hydrology models.

## What was written this run
- REST extract succeeded: **False** (last run)
- If REST failed, synthetic Brays Bayou window `(-95.52, 29.68, -95.36, 29.74)` was used.
- Generated 3 separate flood layers for cumulative frequency analysis.
- Pagination metadata is included in GeoJSON output when REST is used.
- Depth rasters: Must be created manually in ArcGIS Pro from hydrology model outputs.
  For testing, you can create synthetic depth rasters using the Spatial Analyst extension:
  1. Create a constant raster (e.g., 2 ft depth) over the AOI
  2. Clip to flood polygons for each year
  3. Save as depth_2016.tif, depth_2017.tif, depth_2018.tif
- This is training data, not a regulatory floodplain product. Do not file it as FEMA.

## Refresh policy
Re-run `python scripts/build_sample_data.py` when you need a new fixture. Do not
silently replace production GDB layers with this sample pack.

## Using REST URLs in production
For county-wide analysis, you can provide REST URLs directly to the toolbox:
```python
# Example: Load county-wide parcels with pagination
parcels_url = "https://www.gis.hctx.net/arcgishcpid/rest/services/HCAD/Parcels/MapServer/0"
# The tool will automatically paginate if count > 2000
```
